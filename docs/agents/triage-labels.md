# Triage Labels

The skills speak in terms of five canonical triage roles. This file maps those roles to the actual label strings used in this repo's issue tracker.

| Role (English) | Label (Bahasa Indonesia) | Meaning                                    |
| -------------- | ------------------------ | ------------------------------------------ |
| `needs-triage` | `butuh-evaluasi`         | Perlu dievaluasi oleh maintainer           |
| `needs-info`   | `butuh-info`             | Menunggu info tambahan dari pelapor        |
| `ready-for-agent` | `siap-agent`          | Siap dikerjakan oleh AI agent secara AFK   |
| `ready-for-human` | `siap-manual`         | Perlu dikerjakan secara manual oleh manusia |
| `wontfix`      | `tidak-dikerjakan`       | Tidak akan dikerjakan                      |

When a skill mentions a role (e.g. "apply the AFK-ready triage label"), use the corresponding label string from this table.

For local-markdown issue tracker, the `Status:` line in the issue file uses the **Bahasa Indonesia** label.
